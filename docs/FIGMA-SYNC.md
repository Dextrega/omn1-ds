### Open questions for design

1. **`Key/Global/White` still bound in Figma** on ButtonCTA Inverse / Outlined / Actived (fill) and Inverse / Solid / Focused (fill). Components use Semantic only (CLAUDE.md rule 3), so code uses `Surface/Neutral/VerySubtle`. Please rebind in Figma.
2. **ButtonIcon Danger / Outlined Hovered + Pressed** stroke is `Opacity/Secondary/VeryStrong` (a Secondary token on a Danger button). Kept as is.
3. **Drop shadows are not tokens.** The PopOver uses effect style _DropShadow/Level 3_ (`0 8 16 -4 α0.2` + `0 4 12 0 α0.06`). The token pipeline exports no effect styles, so the preset has a `boxShadow` `level-3` with raw black alpha (native uses only the stronger layer). Exporting effect styles from Tokens Studio would remove the approximation.
4. **Spinner Black / White** are Key tokens, as requested; they do not follow the theme (Key/Global flips in Dark, see FINDINGS).
5. **BankFlag**: Figma holds a 40×24 `Brand Payment` component (MasterCard, Visa, AmericanExpress, Elo). Code ships the slot only; export your own logos (trademarks) and pass them as `bankFlag`.
6. State-name typos in Figma (`Actived`, `DIsablede (Filled)`, `Sufffix`) — see FINDINGS.

### Native differences

Native is mobile: no Hovered / Focused / Actived. Pressed → `active:`. Strokes that Figma draws OUTSIDE are an inside `border`,
except the TextInput Active stroke, which is an overlay ring (no layout shift) because it is a real editing state. The PopOver is
a transparent `Modal` positioned from the trigger (Android clips children that overflow their parent). Label colour is separate
from the container so icons can reuse it. Tabs have no indicator animation.

## State mapping

Figma models interaction as variant props. Code uses the platform's own mechanism:

| Figma state               | Web                                                                | React Native        |
| ------------------------- | ------------------------------------------------------------------ | ------------------- |
| Enabled                   | default                                                            | default             |
| Hovered                   | `hover:`                                                           | — (touch)           |
| Pressed                   | `active:`                                                          | `active:`           |
| Focused                   | `focus-visible:` ring (`Stroke/Medium`, `Stroke/Secondary/Medium`) | —                   |
| Actived                   | `aria-pressed="true"` (assumed: a toggled / selected button)       | —                   |
| Active (inputs, checkbox) | `focus-within` / `focus-visible`                                   | focused state       |
| Required                  | `required`                                                         | `required`          |
| Error                     | `error` / `invalid`                                                | `error` / `invalid` |
| Loading                   | `loading` prop                                                     | `loading` prop      |
| Disabled                  | `disabled`                                                         | `disabled`          |

"Actived" is an assumption — confirm with design.
