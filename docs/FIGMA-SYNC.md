### Native differences

Native has no Hovered / Focused / Actived (touch). Pressed → `active:`. Strokes that Figma draws OUTSIDE are an inside
`border`. Label colour is separate from the container so icons can reuse it. Tabs have no indicator animation.

### Figma anomalies kept as in Figma

See [FINDINGS.md](./FINDINGS.md) — code reproduces Figma until design decides which side is the bug.

### API changes in this review (breaking vs. the provisional batch 2)

- **ButtonLink**: lost `loading`, `lg`, and the danger / success / inverse variations (Figma has none); gained `outline`.
- **Tabs**: lost `vertical`; gained `appearance`, `align`, `scrollButtons`.
- **TextInput**: `helper` is deprecated in favour of `hint`; new `counter`, `prefix`, `suffix`, `trailingIcon`, `button`, `link`, `autoCompleted`, `loading`.
- **Chips**: root is `[data-slot=chip]` with an inner `<button aria-pressed>`; new `badge`, `avatar`, `trailingIcon`, `buttonIcon`, `onClose`.

## State mapping

Figma models interaction as variant props. Code uses the platform's own mechanism:

| Figma state               | Web                                                                | React Native        |
| ------------------------- | ------------------------------------------------------------------ | ------------------- |
| Enabled                   | default                                                            | default             |
| Hovered                   | `hover:`                                                           | — (touch)           |
| Pressed                   | `active:`                                                          | `active:`           |
| Focused                   | `focus-visible:` ring (`Stroke/Medium`, `Stroke/Secondary/Medium`) | —                   |
| Actived                   | `aria-pressed="true"` (assumed: a toggled / selected button)       | —                   |
| Active (inputs, checkbox) | `focus-within` / `focus-visible`                                   | focused state       |
| Required                  | `required`                                                         | `required`          |
| Error                     | `error` / `invalid`                                                | `error` / `invalid` |
| Loading                   | `loading` prop                                                     | `loading` prop      |
| Disabled                  | `disabled`                                                         | `disabled`          |

"Actived" is an assumption — confirm with design.
