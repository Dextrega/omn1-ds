Convention: a Figma component whose name starts with `_` is **nested** (not published to the Figma library). Such
components exist in code too (`_TabsBase` → `TabsBase`, `_ButtonList` → `ButtonList`) but are only ever part of a parent.

static Storybook compares computed styles with the token CSS variables, and the Tailwind- / NativeWind-compile tests prove
every class resolves. Colour matrices for ButtonCTA / ButtonIcon are generated by `scripts/gen-button-matrix.mjs` into
literal class strings.

### Open questions for design

1. **ButtonCTA Inverse `Key/Global/White` fills** and 2. **ButtonIcon Danger / Outlined Secondary stroke**: reported as fixed in Figma by design (2026-11-23). Code already used the Semantic equivalents; not yet re-read from Figma — re-verify on the next sync.
2. **Drop shadows are tokens now.** Figma exports no effect styles, so `packages/tokens/effects/effects.json` mirrors _DropShadow/Level 1–4_ (hand-authored, keep in sync). They flow through the pipeline as CSS vars `--omn1-shadow-level-N`, Tailwind `shadow-level-N`, `effects` in `@omn1/tokens`, the `effects` map in `figma-variable-map.json`, and `nativeShadow(step)` (native keeps the strongest layer: React Native has one shadow and no spread). Exporting effect styles from Tokens Studio would let us delete the hand-authored file.
3. **Spinner** colours are all Semantic now (Neutral `OnNeutral/Subtle`, Primary `OnPrimary/Strong`, Black `OnNeutral/VeryStrong`, White `OnNeutral/VerySubtle`); no Key exception.
4. **BankFlag** ships (`@omn1/icons`, web + native): MasterCard, Visa, American Express, Elo at 40×24, from the SVGs supplied by design (brand colours are fixed; they do not follow the theme).
5. State-name typos in Figma (`Actived`, `DIsablede (Filled)`, `Sufffix`) — see FINDINGS.

### Native differences

Native is mobile: no Hovered / Focused / Actived. Pressed → `active:`. Strokes that Figma draws OUTSIDE are an inside `border`,
except the TextInput Active stroke, which is an overlay ring (no layout shift) because it is a real editing state. The PopOver is
a transparent `Modal` positioned from the trigger (Android clips children that overflow their parent). Label colour is separate
from the container so icons can reuse it. Tabs have no indicator animation.

## State mapping

Figma models interaction as variant props. Code uses the platform's own mechanism:

| Figma state               | Web                                                                                                                    | React Native                  |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| Enabled                   | default                                                                                                                | default                       |
| Hovered                   | `hover:`                                                                                                               | — (touch)                     |
| Pressed                   | `active:`                                                                                                              | `active:`                     |
| Focused                   | `focus-visible:` ring (`Stroke/Medium`, `Stroke/Secondary/Medium`)                                                     | —                             |
| Actived                   | `aria-pressed="true"` (assumed: a toggled / selected button); Accordion / Account (they open a panel): `aria-expanded` | `accessibilityState.expanded` |
| Active (inputs, checkbox) | `focus-within` / `focus-visible`                                                                                       | focused state                 |
| Required                  | `required`                                                                                                             | `required`                    |
| Error                     | `error` / `invalid`                                                                                                    | `error` / `invalid`           |
| Loading                   | `loading` prop                                                                                                         | `loading` prop                |
| Disabled                  | `disabled`                                                                                                             | `disabled`                    |

"Actived" is an assumption — confirm with design.
